새 테리를 블록(quad·fine)으로

지금 quad·fine은 1.0.2 옛 그림이에요. 점자용 새 그림을 블록으로 바꾸면 어떻게 보이는지, 실제 카드와 같은 변환 코드(render.js)로 그렸어요. 글자 칸은 10×20픽셀로, 터미널과 비슷한 크기예요.

새로: '큰 머리 + 새 움직임'

몸·다리·움직임(C안 달리기 포함)은 새 그림, 머리는 1.0.2 블록 그림의 큰 머리(늘어진 귀)예요. 머리는 새 그림의 눈 위치를 따라가서 달릴 때 오르내림도 그대로예요. 헥헥의 혀도 예전 머리 것을 써요. 몸은 '중간'만큼 회색을 밝혔고, 머리는 원래 블록용 색 그대로예요.

fine (촘촘한 블록)
quad (사분블록)

점자 칸의 점 모양은 터미널 글꼴마다 달라서 비슷하게만 그렸어요. 달리기는 C안이에요. 자기·짖기 같은 다른 동작은 아직 안 만들었어요.
