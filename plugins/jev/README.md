# jev

Claude Code 에 입력할 때마다 그 말이 아래 두 경우인지 **로컬 판정기**로 가려, 해당하면 Claude 에게 짧은 알림을 넣습니다.

| 게이트 | 이런 말 | Claude 에게 넣는 알림 |
| --- | --- | --- |
| G-1 레퍼런스 | "장비점검대장 화면처럼 버튼 배치해줘" | 지목된 기준은 바꾸지 말고 대상에만 적용, 작업 전 3줄 확인 |
| G-3 결과 거부 | "아까 고친 거 화면에 그대로 나오는데?" | 바로 재시도하지 말고 무엇을 잘못 이해했는지부터 1줄씩 |

판정은 생성 없이 확률만 냅니다(Ollama `bge-m3` 임베딩 + 로지스틱 회귀, 약 0.1초). 입력은 PC 밖으로 나가지 않습니다.

## 준비

1. [Ollama](https://ollama.com) 설치 후 임베딩 모델 받기

   ```bash
   ollama pull bge-m3
   ```

2. `python3` 가 PATH 에 있어야 합니다(표준 라이브러리만 사용, 추가 패키지 없음).

Ollama 가 꺼져 있거나 응답이 늦으면 jev 는 아무것도 하지 않고 넘어갑니다. 작업은 막히지 않습니다.

## 설치

```
/plugin marketplace add d3nims/d3nim-claude-mods
/plugin install jev@d3nim-claude-mods
/reload-plugins
```

## 모드

처음에는 **shadow**(판정만 기록, 알림 없음)로 동작합니다. 내 말투에서 판정이 맞는지 로그로 확인한 뒤 enforce 로 바꾸세요.

`~/.claude/jev/config.json`:

```json
{ "mode": "enforce" }
```

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `mode` | `shadow` | `shadow` 기록만 · `enforce` 알림 넣기 · `off` 끄기 |
| `ollama_url` | `http://127.0.0.1:11434` | `localhost` 는 Windows 에서 약 2초 늦어 IP 로 둡니다 |
| `embed_timeout_sec` | `8` | 재부팅 직후 모델 적재(수 초)까지 기다리는 한도 |
| `log` | `true` | 판정 기록. 입력 앞 120자가 로컬 로그에 남습니다 |

환경변수 `JEV_MODE`, `JEV_OLLAMA_URL`, `JEV_LOG` 로도 바꿀 수 있습니다.

## 로그 보기

`~/.claude/jev/jev.log` 에 한 줄씩 쌓입니다.

```json
{"mode": "shadow", "ms": 95, "prompt": "아까 고친 거 화면에 그대로 나오는데?", "jev": {"g1": 0.004, "g3": 0.973}, "hit": ["g3"]}
```

`jev` 는 게이트별 확률, `hit` 은 기준값(G-1 0.60, G-3 0.65)을 넘은 게이트입니다.

## 알아둘 점

- 판정기는 특정 회사·프로젝트 대화 없이, 일반 개발 상황을 다룬 합성 문장 1,829건(한국어·영어)으로 학습했습니다.
- 실제 업무 대화 1,855건(학습에 쓰지 않음)으로 시험한 F1 은 G-1 0.42, G-3 0.37 입니다. G-3 는 길고 여러 지시가 섞인 불만을 아직 놓치는 편이고, "내가 착각했네" 같은 자기 정정을 거부로 잘못 보기도 합니다. 그래서 처음엔 shadow 로 두고 로그로 확인하세요.
- 다른 세션·서브에이전트가 보낸 메시지와 작업 알림은 판정하지 않습니다.
- 재부팅 직후 첫 입력만 모델 적재로 4~5초 걸리고, 그다음부터는 약 0.1초입니다.
